# lifebucket

LifeBucket: tu vida es un balde de horas por semana y la app te muestra con qué lo estás llenando (Trabajo, Cuerpo, Mente, Disfrute, Vínculos y Libre).

## Correr en local

```bash
npm install
cp .env.example .env.local   # opcional: claves para IA y voz
npm run dev                  # http://localhost:3000
```

Más detalle en `CLAUDE.md`, `PRODUCT.md` y `DESIGN.md`. Decisiones en `docs/decisiones.md`.
